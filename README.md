# Abomination

A retro first-person shooter inspired by **Quake (1996)**, built from scratch
with modern C++ and OpenGL 4.6.

> **Status:** early development (pre-0.1). Nothing playable yet.

## About

- 4 episodes × 5 levels, a boss at the end of every episode
- Fast, Quake-style movement and a varied arsenal
- Ground, flying, wall-jumping and teleporting enemies
- Retro look: low-poly models and low-resolution textures, lit by a modern
  renderer (baked lightmaps, dynamic lights, HDR, bloom)

## Tech

C++23 · OpenGL 4.6 Core · SDL3 · EnTT · glm · CMake · vcpkg · GoogleTest

Platform: Windows (Visual Studio / MSVC).
